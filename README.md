# DSJester · F-14 大肥鱼后座

给原版 Heatblur F-14 添加自然语言后座指令、游戏内文字回复和会随飞行事件反应的小鲸鱼二维伙伴。采用 Saved Games 插件，保留原版飞机和 Jester 的自动工作。

**当前版本：1.0.4。界面以中文为主，角色语音仍未完善。**

- [下载主模组、可选声音包和校验文件](https://github.com/David-Sophon/DSJester/releases/latest)
- [安装教程与用户手册](README-发布版与用户手册.md)
- [反馈问题](https://github.com/David-Sophon/DSJester/issues)

请在 Releases 下载 `DSJester-v1.0.4.zip`。主模组包包含完整的本版 Python/Lua 源码、素材、安装工具及开发文档。GitHub 自动生成的 Source code 压缩包仅对应此下载导航仓库，不能替代主模组包。

## 功能

- 本地 Vosk / Whisper 语音识别，或直接输入文字。
- DeepSeek 理解自然语言，通过受控工具调用后座功能。
- 游戏内独立文字框、可选无线电文字、二维伙伴的动作和点击交互。
- 本机 F-14 手册检索、可选事件回复与低频闲聊。
- 可配置的附近飞机辅助报点；此功能使用允许的全局导出数据，不等同于雷达或 IFF。
- DCS 原生键盘和外设绑定，默认左 Ctrl + 左 Alt + 空格，按住说话、松开提交。

## 安装前准备

需要 Windows、DCS World、已购买并安装的 Heatblur F-14、Python，以及玩家自己的 DeepSeek API Key。语音识别依赖和模型按手册另行下载。解压主模组后按手册运行 `dcs/install.cmd`，配置 DCS 专用设置，并完全重启 DCS。

小鲸鱼实验声音包是可选下载，约 242 MB，仅含基础权重、社区参考音频和配置工具；完整 GPT-SoVITS 推理环境及额外前端模型需要另备。它不是 DeepSeek 官方 App 声音，也不包含 Jester 原声或派生训练权重。建议先使用文字输出或 Windows 系统语音。

## 1.0.4 更新

声音选择和关闭现在会在请求忙碌、语音识别配置出错时立即应用，并阻止已关闭或切换后残留的 Windows 语音开始播放。73 项界面测试和 10 项模拟声音测试通过，实际角色语音播放仍待复测。1.0.3 的原生改键修复已获用户实机确认。

## 已知限制与隐私

目前 RWS / TWS AUTO 有可用的实机反馈；其他雷达模式和完整 AWG-9 目标、IFF 数据仍有限制。自动报点、详细航母事件、全部机型外设组合、联机完整性与 VR 仍需进一步验证。发布版本不代表全部功能已验收。

常规语音识别在本机完成；识别文字和相关飞行、座舱状态会发送给玩家配置的 DeepSeek 服务。事件 AI 和闲聊可以关闭。请勿上传自己的 API Key 或个人配置。

独立社区项目，与 Eagle Dynamics、Heatblur、DeepSeek 无隶属关系。主包不包含官方飞机文件、Jester 音频或本机运行数据。第三方模型许可与来源说明随可选包提供。
